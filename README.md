# Wordroom · 单词自习室

本地英语单词学习网页，Python 3.10 或更高版本即可运行，无需安装额外依赖。

## 环境要求（Requirements）

- Python 3.10 或更高版本，包含标准库 `sqlite3`。运行项目无需 `pip install`、Node.js 或前端构建。
- 可运行现代 JavaScript 的浏览器。朗读使用浏览器和系统提供的语音合成能力。
- 本地 ECDICT 格式的 SQLite 词典数据库（`dict.db`）。准备词典时可参考 [ECDICT 项目](https://github.com/skywind3000/ECDICT)；本项目读取 `stardict` 表中的 `word`、`phonetic`、`definition`、`translation`、`collins`、`tag`、`exchange` 字段。
- 英文补充词库使用免费的 [Open English WordNet 2025+](https://github.com/globalwordnet/english-wordnet/releases/tag/2025-edition)，首次下载需联网，安装后离线使用。无需 API 账号或付费订阅。
- 如需通过 GitHub 同步分类与进度，需安装 Git，并具备本仓库的读写权限。运行测试时，前端状态测试额外需要 Node.js，日常学习不需要。

词典数据库需在每台电脑上单独准备，不随 Git 仓库上传。单词、简单词分类和学习记录保存在 `words/` 的 JSON 文件中，随仓库一起同步。

## 启动

新电脑先克隆项目，然后指定本机词典路径启动：

```powershell
git clone https://github.com/jianxing04/English-Word-Learning.git
cd English-Word-Learning
python app.py --dict "D:\Dictionaries\dict.db"
```

首次使用时，在项目目录安装英文补充词库：

```powershell
python tools/setup_wordnet.py
```

脚本从项目官方站点下载约 12.3 MiB 的固定版本数据，校验 SHA-256 后生成约 28.3 MiB 的 `data/wordnet.db`。只使用 Python 标准库，不需要安装第三方包。已安装时不会重复下载；重建可加 `--force`。已经下载官方压缩包时可使用 `--source "压缩包路径.xml.gz"`。词库没有安装或未收录某词时，ECDICT 仍可正常使用。

默认自动加载 `data/wordnet.db`；如需放在其他位置，可给安装脚本传 `--output`，给应用传 `--wordnet` 或配置 `WORDROOM_WORDNET` 环境变量。换电脑拉取代码后，在该电脑同样运行一次安装脚本即可，不需要通过 Git 上传词典文件。

将示例中的词典路径替换为实际文件路径。也可以通过环境变量配置，再运行启动脚本：

```powershell
$env:WORDROOM_DICT = "D:\Dictionaries\dict.db"
.\start.bat
```

已配置词典路径后，双击 `start.bat`，浏览器会自动打开 http://127.0.0.1:8765 。运行时保持命令窗口开启，关闭窗口或按 Ctrl+C 可停止服务。

也可以在项目目录运行：

```powershell
python app.py
```

默认只在本机提供服务。更换端口或词典位置：

```powershell
python app.py --port 8766 --dict "D:\My_Codes\MyEnglishApp\data\dict.db"
```

## 单词本

网页左侧是 `words/` 目录的文件浏览器。点击文件夹进入，点击顶部路径或“返回上一级”返回；词表按自然数字顺序排列，WL2 在 WL10 前面。

将新词表或整个词表文件夹放进 `words/` 后点击“我的单词本”右侧刷新。无论当前停在哪个文件夹，刷新都会递归扫描整个 `words/`（包含新建的 IELTS 等子目录），先导入新词表，再更新全局搜索和当前结果，并提示同步的词本数、新导入数量。无需重启服务器。支持：

- TXT：每行一个英文单词或短语，允许单词内的空格、连字符及撇号。空行和以 `#` 开头的行会忽略。
- CSV、TSV：优先读取 `word` 或 `单词` 标题对应的列；无标题时读取第一列。
- JSON：使用下方的新格式；也兼容导入字符串数组、`[{"word":"minor"}]` 和 `{"words":["minor"]}` 等旧格式。

支持 UTF-8 和 GB18030 文本。重复词不区分大小写，保留第一次出现的词；不擅自修改词表拼写。词典未收录的词会明确提示。

也可以用 `python app.py --words "你的词表目录"` 浏览其他本地目录。

启动时以及浏览目录时，旧 TXT、CSV、TSV 和旧格式 JSON 会转换为同名的新格式 JSON。原文件先备份到词表目录同级的 `.runtime/wordbook-backup/`，转换成功后从词表目录移除旧文件，避免重复显示。相同名称的旧文件与 JSON 同时存在时不会覆盖，请先核对内容。

## 修改单词本

点击左侧“修改单词本”，可以选择任意目录中的词本。编辑时仅显示合并后的原始词汇列表，每行一个词；原词本、简单词、释义、扩展词组和学习操作暂时隐藏，键盘恢复正常的文本编辑行为。可以增加、删除、修改或调整单词顺序，点击“保存修改”直接更新对应 JSON，并同步全局搜索；“取消修改”丢弃当前未保存的输入并返回学习。

未改动的词保留简单词分类、学习记录和扩展词组；新增或改了拼写的词按新词加入原词本，不继承旧词的搭配。删除词会移除其搭配。空行忽略，重复词不区分大小写并合并。编辑顺序保存在 `word_order`，以后移入或移出简单词不会打乱编辑列表的顺序；阅读模式仍按原来的规则随机排列。学习位置和检查记录继续通过单词身份对应，删除或调整顺序不会把历史错记给另一个词。

每次修改前自动将原 JSON 备份到本地 `.runtime/wordbook-edits/`。如果文件已被另一页面或 Git 同步更新，旧编辑会被拒绝，输入保留，避免覆盖新记录；可复制修改后点击“放弃修改并重新加载”再合并。备份不随 Git 上传，编辑后的词本 JSON 正常参与同步。

## 全局单词搜索

页面顶部的“全局单词搜索”会汇总 `words/` 下所有子目录的词本，包含原词本与简单词。同词不区分大小写，只显示一条结果，并列出它所在的所有 WL 和各自分类；原词本文件、分类和学习进度继续独立保存。点击“查看全部单词”可分页浏览按字母排列的去重词表。

输入单词或拼写片段后自动搜索，排序为：完全匹配 → 前缀匹配 → 中间或后缀包含匹配，同一组内按字母排序。例如搜索 `infer` 可一起找到 `infer`、`inference`；搜索 `tech` 时，`technical`、`technology` 等前缀匹配排在 `polytechnic` 等包含匹配前（以当前词本实际收录为准）。使用字面子串匹配，不作词根推断或模糊纠错。

结果展示中文释义并高亮匹配部分。同词的所有来源均列为按钮，标签包含目录和词本名，例如 `IELTS / WL01 · 原词本`、`考研词汇 / WL18 · 简单词`，即使不同目录的词本重名也能区分。点击任一来源，会在该词所在的原词本或简单词本中打开阅读模式，定位到这个词；只搜索不会改变学习位置。结果独立滚动、每页 30 个，不会一次展开整套词表。新增、删除词本或调整简单词分类后，下一次搜索会重新读取索引；点击左侧刷新会先完成全部子目录的导入，再更新当前结果，来源使用导入后的 JSON 路径。无需额外词典、依赖或联网服务。

## 简单词本

每个单词本都有独立的“简单词本”。阅读或背诵时点击“移入简单词”，该词会从原词本的学习列表移出，以后打开原词本时自动排除。

点击上方“简单词本”或左侧词本下的“简单词本”条目，可以照常阅读、测试这些词。遗忘时点击“放回原词本”，它便回到对应的原词本；答错不会自动移回，由你自行决定。两个分类的阅读和拼写进度分别保存。

每个 WL 对应一个 JSON 文件，例如 `words/Postgraduate-Entrance-Examination/WL1.json`：

```json
{
  "version": 2,
  "words": ["minor", "faithful"],
  "easy_words": ["contagious"],
  "progress": {},
  "settings": {"batch_size": 1},
  "revision": 0
}
```

`words` 是非简单词（原词本），`easy_words` 是简单词。移入或放回操作直接修改对应 JSON 的这两个数组，成功保存后才切换页面中的单词；词典数据库保持只读。相同单词在不同 WL 中独立管理。

### WL1 语境记忆试点

WL1 的每个词（包括简单词）增加了按常见词性和义项整理的学习搭配。它们是为学习编写的短语或短句及中文对应，方便在具体语境里记忆；页面不会将这些练习内容标作权威词典原文。暂时只为 WL1 编写内容，其他词本按原方式阅读。

为保留现有分类数组与学习进度，搭配按单词放在同一本 JSON 的 `word_details` 中，例如：

```json
{
  "word_details": {
    "minor": {
      "contexts": [
        {"pos": "adj.", "meaning": "轻微的", "english": "a minor mistake", "chinese": "一个小错误"},
        {"pos": "n.", "meaning": "未成年人", "english": "protect minors", "chinese": "保护未成年人"}
      ]
    }
  }
}
```

上面仅展示新增字段，实际文件继续保留 `words`、`easy_words`、`progress` 等原字段。每个词还可选填 `note`（搭配或用法说明）及 `display_word`（搭配中采用的显示词形），不会因此修改原单词或答题匹配规则。移入、移出简单词及保存进度都会保留这些搭配，随 WL1 JSON 一起通过 Git 同步。

语境记忆只在阅读模式展示，英文中的目标词及已有词形会高亮。隐藏单词或隐藏释义时，整个搭配区先隐藏，按空格揭示后一起显示；进入下一词重新隐藏。拼写和批量背诵模式不展示这部分内容。

`progress.main` 和 `progress.easy` 分别保存两类词的阅读位置与顺序、拼写位置、检查记录以及未完成的批量练习；`settings.batch_size` 保存每组数量。页面底部显示文件保存状态，写入失败可以点击重试。文件采用原子替换保存；其他页面或 Git 同步已修改同一本文件时，会阻止旧页面覆盖，并提示刷新。

首次使用新版页面时，会自动把当前浏览器旧版 localStorage 中的分类和进度迁入尚未开始使用的新 JSON，且只迁入一次；旧浏览器记录保留作备份，后续以文件内容为准。迁移需在原来使用的浏览器配置和原网址（例如 `http://127.0.0.1:8765`）打开新版页面。已经产生新版学习记录的 JSON 不会被其他浏览器中的旧记录覆盖。

## 在其他电脑同步

把项目代码及 `words/` 下的 JSON 一起提交到 GitHub，学习后先确认页面显示“已保存到 JSON”，再提交并推送改动。换电脑时先拉取最新文件，再启动或刷新网页，即可读取相同分类和进度。JSON 本身就是数据来源，更换浏览器或清理浏览器数据不会清除它们；模式、隐藏显示等界面偏好仍由各浏览器保存。

学习结束后，在项目目录保存并上传词本记录（有修改时再提交）：

```powershell
git status --short
git add -- words
git commit -m "Save vocabulary learning progress"
git push
```

另一台电脑开始学习前，先同步，再启动项目或刷新已打开的网页：

```powershell
git pull --ff-only
python app.py --dict "D:\Dictionaries\dict.db"
```

这不包含自动 Git 提交、推送或拉取。在不同电脑交替学习前先同步，避免同时修改同一个 WL；若 Git 提示冲突，需要合并 JSON 后再运行。外部词典数据库需在另一台电脑另行配置，可通过 `--dict` 参数或 `WORDROOM_DICT` 环境变量指定。

`.gitignore` 排除词典数据库、本地 `data/` 与 `dictionaries/`、`.runtime/` 下的日志和备份、Python 缓存、虚拟环境及本机配置；不会忽略 `words/` 中的 JSON。`.gitattributes` 统一代码与 JSON 的换行，Windows 启动脚本保留 CRLF，方便不同电脑同步。

## 键盘规则

背诵模式可在“每次背诵”中选择“单个单词”“5 个单词”或“10 个单词”。单个模式沿用下表规则。

批量模式从当前位置向后加载指定数量的单词，最后一组不足时显示剩余词。每个释义对应一个输入框，可以用鼠标自由选择顺序；回车检查当前框，答错留在原框，答对保留填写内容并选择本组下一个尚未答对的框。整组全部答对后，所有输入框才一起清空，仍停留在原组，焦点回到第一个框，可以按空格进入下一组，或重新输入再练一轮。单词组采用独立滚动区域，鼠标滚轮或触摸滑动只滚动组内内容，滚动到顶部或底部也不会继续带动整个网页。回车切换焦点时只在该区域内将待填写输入框平滑滚动到中央附近；区域边界处尽量保持可见，系统设置减少动画时直接滚动。开始重练会重置本组的通过状态，需整组再次通过后才能按空格继续。空输入重复按回车不会换组或清除刚才的判断，最后一组也必须按空格才显示完成。按住 Tab 查看当前输入框的完整单词，松开隐藏提示并继续输入；左右键在本组输入框之间移动。每行都可以移入简单词或放回原词本，简单词本同样支持批量测试。

批量大小、当前组、已检查结果和未完成输入保存在对应 WL 的 JSON，刷新、重启服务器，或同步文件到其他电脑后可继续。切换组大小会重新开始当前组。

每批仍从当前词表位置选取固定的 5 或 10 个词，但首次训练时会随机排列。整组通过并统一清空后，同一组会重新洗牌，准备下一轮；多于一个词时，新顺序保证与上一轮不同。输入过程中不改变顺序，刷新恢复未完成练习时保留当前顺序及填写结果。显示编号表示本轮位置；学习进度、答案判断与简单词分类始终按实际单词记录。

| 操作 | 阅读模式 | 拼写学习 |
| --- | --- | --- |
| 回车 | 原词本：移入简单词并显示下一个；简单词本：放回原词本并显示下一个 | 检查答案，提示正确或错误，停留在当前单词；答对后自动清空输入并聚焦，方便再练一遍 |
| 空格 | 全部显示时进入下一词；隐藏模式下先揭示，再按一次进入下一词；读完后在完成页按空格从头再读 | 检查正确后进入下一词；检查错误后清空输入，停留在当前词重试 |
| 左 / 右箭头 | 切换到上一个 / 下一个词 | 直接切换到上一个 / 下一个词，清空输入和判断；输入框内也可使用 |
| 按住 Tab | 正常切换焦点 | 在学习区按住可临时查看完整单词，松开恢复原来的显示，输入框保持聚焦，可继续输入 |
| 修改已检查答案 | — | 作废上次判断，必须再次按回车 |

答对后清空输入仍保留本次正确判断，可以直接按空格进入下一词。若重新输入，必须再次按回车检查；空输入时重复按回车不会换词，也不会清除刚才的正确判断。

Tab 提示不检查答案、不清空输入、不换词。窗口失去焦点或切换到其他页面时，临时提示会自动收起。Shift+Tab 保留正常的反向焦点导航。

左右箭头可自由查看和练习词表中的单词，不要求先答对，也不会将跳过的词计为已掌握。到达第一个或最后一个词后不会循环跳转；完成页面按左箭头可回到最后一词。Ctrl、Alt、Shift 等组合键保留原来的浏览器或文本编辑行为。

拼写模式初始只显示中文释义，检查后才显示答案、音标及英文解释。匹配忽略大小写和前后空格，统一全角字符、弯引号和短语中连续空格；连字符、拼写和词形仍需正确。输入短语时，检查之前的空格照常输入，不触发跳转。支持鼠标点击检查和继续。

阅读模式默认同时显示 ECDICT 中文释义、Open English WordNet 英文义项与同义词，以及原有 ECDICT 英文释义和词形：宽屏补充内容放在单词右侧，窄屏放在下方，无需点击展开。较长的 WordNet 义项列表可独立滚动。单词拼写检查后显示英文补充；批量模式也在对应单词检查后显示，重练时恢复隐藏。

阅读模式可在“阅读显示”中选择“全部显示”“隐藏释义”或“隐藏单词”。隐藏释义时中文和英文释义一起隐藏；隐藏单词时单词、音标及词形隐藏。第一次按空格揭示当前词，第二次进入下一词，并重新隐藏。鼠标点击“显示释义 / 显示单词”按钮也可揭示。原词本和简单词本均支持，显示选择会保存到当前浏览器。

每次打开、刷新阅读词本，或切换回阅读模式，都会随机打乱本轮尚未读过的单词；已读部分和已读数量保留，不会因为重新排列漏词。当前页面内揭示、前后切换及移动简单词不会重新洗牌。阅读顺序与拼写顺序分别记录，拼写检查和批量练习不受阅读洗牌影响。

阅读完当前词本后，在完成页按空格即可重新打乱整本词并开始新一轮，也可以点击“从头再读”。原词本和简单词本均支持；重新开始会保留阅读显示设置，并重新隐藏所选内容。

阅读原词本时，按回车会把当前词移入该词本的简单词本，并接着显示下一个词；隐藏释义或隐藏单词时也适用。阅读简单词本时，回车会把当前词放回对应的原词本，并继续显示下一个简单词；如果只想浏览下一词，可以按空格或右箭头。长按回车不会连续移动多个词；浏览文件夹、选择模式或操作下拉框时保留控件本来的回车行为。

学习进度按单词身份对应；移词、恢复词和重新排列不会把某个词的检查记录错记到相邻词。阅读和拼写的进度分别保存。关闭页面前确认文件保存状态；关闭或重启服务器不会清除已保存的数据。
